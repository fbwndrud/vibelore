# 모델 설정

한국어 | [English](MODELS.en.md)

소설을 쓰는 **텍스트 모델**과 웹툰을 그리는 **이미지 모델**은 별도로 선택합니다.
vibelore를 설치한다고 특정 모델에 대한 이용 권한이나 이미지 생성 기능이 추가되지는 않습니다.

## 소설은 어떤 모델로 쓰나요?

기본적으로 연결한 AI 앱·CLI의 현재 모델이 계획·초고·검토 요청에 답합니다.
모델과 생각 수준은 그 앱·CLI에서 선택하세요. 기본 소설 집필을 위해 vibelore에
모델 제공사의 API 키를 따로 넣을 필요는 없습니다.

> 현재 선택한 모델로 이 작품을 집필해 줘. 모델 실행을 바꿔야 한다면 먼저 알려 줘.

vibelore의 검사와 승인 절차는 모델 선택과 별개로 유지됩니다.
이 문서는 모델별 품질 순위나 속도를 보증하지 않습니다.

## 웹툰 이미지 모델은 어떻게 정하나요?

AI가 모델·실행 경로·비용을 먼저 확인하고, 사용자가 확정한 선택을 작품별로 저장합니다.
같은 작품의 다음 컷과 회차에도 그 선택을 사용합니다.

| 실행 경로 | 필요한 것 | 실행 주체 |
|---|---|---|
| 호스트 내장 이미지 도구 | 해당 도구를 사용할 수 있는 호스트 환경과 한도 | 호스트 AI |
| 이미지 API | 선택 모델을 호출할 도구, 키, 계정 권한과 별도 과금 동의 | 호스트 AI의 API 실행 환경 |

vibelore 서버는 이미지 요청과 참조·반입·승인을 관리하며 API를 직접 호출하지 않습니다.
서버가 모델 이름을 받아들여도 계정에서 실제 사용할 수 있다는 뜻은 아닙니다.
실행 가능한 모델·경로인지 확인한 뒤 생성합니다. 실행 불가나 한도 초과를 이유로
다른 모델 또는 유료 경로로 자동 변경하지 않습니다.

> 웹툰에 사용할 이미지 모델과 실행 가능한 경로를 확인해 줘. 별도 비용이 발생하는지 먼저 설명하고 내 선택을 이 작품에서 유지해.

구체적인 제작 순서는 [웹툰 만들기](WEBTOON.md)를 보세요.

## 선택 기능: 로컬 텍스트 모델

로컬 모델을 직접 운영하는 사용자는 OpenAI 호환 `/chat/completions` 엔드포인트를 연결할 수
있습니다. 두 환경 변수를 **MCP 서버가 실행되는 환경**에 함께 설정합니다.

```bash
VIBELORE_LOCAL_BASE_URL=http://127.0.0.1:11434/v1 \
VIBELORE_LOCAL_MODEL=your-installed-model \
node /absolute/path/to/vibelore/src/server.js
```

`your-installed-model`은 설치한 실제 모델 ID로 바꾸세요. 두 값이 설정되면 호스트의
텍스트 응답 대신 해당 엔드포인트를 사용합니다. 이는 이미지 생성 설정이 아닙니다.

현재 어댑터는 인증과 생각 수준 전달을 지원하지 않습니다. 신뢰하는 로컬 엔드포인트에서만
사용하고, 모델의 장문·구조화 응답이 작품 작업에 적합한지 먼저 확인하세요.

## 고급 설정: 집필 단계별 모델 힌트

일반 사용에서는 설정하지 않아도 됩니다. 직접 연동한다면 `lore_write`의 `modelProfile`로
단계별 요청 모델을 기록할 수 있습니다. 값은 모델 ID 또는 `{ provider, modelId, reasoningEffort }`입니다.

- `default`: 기준 모델
- `light`: 계획(`planning`)·초고(`draft`)·advisory 검토(`review`)에 적용할 가벼운 모델
- `identity`, `planning`, `draft`, `review`, `quality`, `final`: 개별 단계 지정

`review`는 coherence·편집·인물·독자 견인·아크·프로필 이탈 검토처럼 결과가 advisory로만
남는 단계이고, `quality`는 상태 추출·의미 연속성 검사·pattern ledger처럼 답이 정본 상태나
다음 화 제약으로 들어가는 단계입니다. `light`는 `review`에는 적용되지만 `quality`에는
적용되지 않으므로, 가벼운 모델을 지정해도 확정 사실 추출은 기준 모델이 맡습니다.
`quality`를 바꾸려면 명시적으로 지정하세요.

명시한 단계 값 → 해당 단계의 `light` → `default` 순으로 모델을 선택합니다.
이 값은 호스트에 전달되는 **힌트**이며 세션 모델을 강제로 전환하는 기능은 아닙니다.
로컬 어댑터는 `provider: "local"`로 지정한 모델 ID를 요청에 적용합니다.
프로필은 해당 집필 작업을 재개할 때도 유지됩니다.

인자 예시는 [집필 도구 레퍼런스](TOOLS.md#lore_write), 실제 호스트 확인 기록은
[HOSTS.md](../HOSTS.md)를 참고하세요.
