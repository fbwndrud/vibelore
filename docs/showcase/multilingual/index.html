8개 언어로 쓰고 그리기

같은 도구로 여덟 언어의 작품을 설계하고 1화를 쓴 뒤, 첫 장면을 웹툰 한 장으로 그렸습니다. 소설과 대사는 각 언어 원문 그대로 싣고 번역하지 않습니다. 결과와 검토 판정은 첫 결과 그대로입니다.

소설 1화

언어마다 작품 발견 인터뷰부터 1화 커밋까지 공개 MCP 도구만으로 진행한 수락 테스트 결과입니다.

장면 웹툰 한 장

읽는 법과 한계

  • 소설 모델은 모든 언어에서 claude-sonnet-5, 웹툰 각색 호스트는 claude-opus-5-5, 이미지 모델은 gpt-image-2.5-sunburst입니다.
  • 그림 검토는 제작을 조율한 Claude Code 세션(claude-opus-5-5)이 이미지를 확대해 읽고 적은 자기검토이며 독립 평가가 아닙니다. 검토 문장은 기록된 영어 원문 그대로 싣습니다.
  • 웹툰은 언어마다 이미지 한 장만 만들었습니다. 검토에서 떨어진 장면에 대해 도구가 자동 재계획을 시작했지만, 두 번째 이미지는 만들지 않았습니다.
  • “계획과 다른 줄”은 검토자가 계획 문자열과 글자 단위로 다르다고 적은 줄입니다. 도구가 같은 것으로 받아들인 차이(예: 강조 기호 제거)도 포함합니다.
