햇빛을 찾아 나서는 작은 가출

퇴근하고 돌아온 자취 초보 직장인 시우. 매일 꼬박꼬박 물을 줬는데, 다육이 동글이가 빈 화분과 쪽지만 남기고 사라졌다. “물은 됐고요, 햇빛 찾으러 갑니다.” 창가의 바질 선생은 대뜸 환기부터 하란다. 작은 뿌리 자국을 따라 올라가다 보면, 식물에게도 이웃에게도 저마다 필요한 자리가 있다는 걸 알게 된다.

초보 집사의 실수와 식물들의 요구를 생활 코미디로 옮겼습니다. 로맨스보다 이웃과 우정, 웃긴 소동 끝에 남는 작은 애정을 중심에 두었습니다. 공개 범위는 완성된 소설 1~3화와 웹툰 1화입니다.

누가 무엇을 만들었나

소설은 Antigravity CLI의 gemini-3.8-flash-medium으로 집필했습니다. 웹툰 장면 계획·사전 검증·그림 검토는 Codex가 담당했습니다. 해당 호스트의 정확한 모델명은 기록되지 않았습니다.

장면 이미지 네 번의 API 요청에는 gpt-image-2.5-sunburst를 지정했습니다. 기준 이미지는 별도로 내장 image_gen 도구에서 만들었고, 모델명은 기록되지 않았습니다. 소설 정본은 각색 과정에서 수정하지 않았습니다.

한 번 다시 그린 장면

웹툰 1화는 3장면·24칸입니다. 두 번째 장면은 바질 화분이 책상에서 바닥으로 이동한 오류 때문에 한 번 다시 그렸으며, 이전 그림과 판정도 공개합니다. 한국어 대사 27개는 원문을 유지했습니다. 그림 검토는 제작을 조율한 Codex의 자기검토이며 독립 평가가 아닙니다.

수정 후에도 말풍선 읽기 순서, 이른 웅크림 자세, 발바닥처럼 보이는 흙자국, 원문에 없는 가방, 압축된 방 구조는 참고 의견으로 남겼습니다. 리더의 ‘제작 정보’를 켜면 장면별 근거와 수정 전 그림을 볼 수 있습니다.

비용과 시간의 기록 범위

장면 이미지 API는 총 4회 호출했습니다. 세 장면의 채택 이미지 3장과 수정 전 이미지 1장을 포함해 호출 시간 합계는 151.8초입니다(37.5 + 39.2 + 38.2 + 36.9초). 기준 이미지 생성 1회는 이 합계에 포함하지 않았습니다.

실제 결제 금액, 소설·각색·검토의 전체 소요 시간, API 응답의 관측 모델명은 기록되지 않았습니다. 비용을 0달러로 계산하거나 모델 호출 시간과 작업 전체 시간을 섞지 않았습니다.

이미지는 별도 이미지 저장소에, 목록용 작은 표지는 본 저장소에 등록했습니다. 리더 데이터에는 공개 원문·계획·검토만 담고 내부 파일 경로는 제외했습니다.
