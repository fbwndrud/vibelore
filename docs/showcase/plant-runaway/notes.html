햇빛을 찾아 나서는 작은 가출

퇴근하고 돌아온 자취 초보 직장인 시우. 매일 꼬박꼬박 물을 줬는데, 다육이 동글이가 빈 화분과 쪽지만 남기고 사라졌다. “물은 됐고요, 햇빛 찾으러 갑니다.” 창가의 바질 선생은 대뜸 환기부터 하란다. 작은 뿌리 자국을 따라 올라가다 보면, 식물에게도 이웃에게도 저마다 필요한 자리가 있다는 걸 알게 된다.

초보 집사의 실수와 식물들의 요구를 생활 코미디로 옮겼습니다. 이웃과 우정, 웃긴 소동 끝에 남는 작은 애정을 중심에 두었습니다. 공개 범위는 완성된 소설과 웹툰 모두 1~3화입니다.

이번 회차의 연출

2화는 민트색 바람길이 칸 사이와 건물 전경을 이어 갑니다. 말하는 화분 앞에서 작아진 시우의 몸짓, 이웃의 문과 각진 구도, 청소 뒤 다시 나타나는 바람 리본으로 긴장과 용기를 이어 붙였습니다.

3화는 잎사귀 전경과 식물 눈높이에서 정원을 보여 줍니다. 작은 화분에게는 시우의 슬리퍼도 거대한 침입자입니다. 동글이를 구한 뒤 대야를 걷어차는 장면은 둥근 충격과 물결 구도로 소음을 펼치고, 얼어붙은 식물들과 강한 창문 불빛으로 할머니의 등장을 끊어 읽습니다.

누가 무엇을 만들었나

소설은 Antigravity CLI의 gemini-3.8-flash-medium으로 집필했습니다. 웹툰 장면 계획·사전 검증·그림 검토는 Codex가 담당했습니다. 해당 호스트의 정확한 모델명은 기록되지 않았습니다. 소설 정본은 각색 과정에서 수정하지 않았습니다.

장면 이미지 API 요청에는 gpt-image-2.5-sunburst를 지정했습니다. 응답의 실제 모델명은 따로 기록되지 않았습니다. 1화 기준 이미지는 내장 image_gen 도구(모델명 미기록), 2·3화 기준 이미지는 Sunburst API로 만들었습니다. 새 기준 이미지는 할머니의 은백색 머리 디자인을 맞추기 위해 한 번 수정했습니다.

다시 그린 네 장면

웹툰 1~3화는 10장면·80칸입니다. 원문에서 고른 한국어 문구 79개를 이미지에 넣었습니다. 1화 2장면은 바질 화분의 위치, 2화 1장면은 인용부호, 2화 4장면은 창틀 화분과 문턱의 잘못된 소품, 3화 2장면은 말풍선 꼬리 때문에 각각 한 번 다시 그렸습니다. 이전 이미지와 실패 판정도 리더에 남겼습니다.

채택 이미지에도 구도 압축, 이른 앉은 자세, 좌우 손 표현, 가방 소품, 문 잠금과 조명 연결 등의 참고 의견이 있습니다. 제작 정보에서 장면별 근거를 볼 수 있습니다. 그림 검토는 제작을 조율한 Codex의 자기검토이며 독립 평가가 아닙니다.

비용과 시간의 기록 범위

장면 이미지 API는 총 14회 호출했습니다. 채택 이미지 10장과 수정 전 이미지 4장을 포함한 호출 시간 합계는 547.7초입니다. 기준 이미지 생성 3회는 이 합계에서 제외했습니다. 이 중 새 기준 이미지 API 2회의 합계는 77.4초이며, 이전 내장 도구 호출 시간은 기록되지 않았습니다.

실제 결제 금액, 소설·각색·검토의 전체 소요 시간, API 응답의 관측 모델명은 기록되지 않았습니다. 비용은 기록 없음으로 표시했습니다.

이미지는 별도 이미지 저장소에, 목록용 작은 표지는 본 저장소에 등록했습니다. 리더 데이터에는 공개 원문·계획·검토만 담고 내부 파일 경로는 제외했습니다.
