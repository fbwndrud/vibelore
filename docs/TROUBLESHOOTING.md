# 문제 해결과 백업

다시 처음부터 요청하기 전에 **작업이 어디서 멈췄는지** 먼저 확인하세요. 진행 상태와 후보는
저장되어 있어서 대부분 같은 작업을 이어갈 수 있습니다.

## 도구가 보이지 않아요

1. AI 도구를 완전히 껐다가 다시 켭니다. 새 세션을 열어도 됩니다.
2. Node.js 버전이 22.13 이상(22.x) 또는 24.x인지 확인합니다.
3. AI에게 이렇게 물어봅니다.

> vibelore MCP 서버가 등록된 경로가 실제 설치 폴더와 같은지 확인하고, 연결 상태를 알려 줘.

그래도 안 되면 [연결 진단](OPERATIONS.md#연결-문제)을 보고 오류 메시지와 함께 문의하세요.
공개 이슈에는 API 키, 원고 전문, 개인 경로를 그대로 올리지 마세요.

## 작업이 중간에 멈췄어요

> 진행 중인 소설 작업이 왜 멈췄는지 확인하고, 저장된 곳에서 이어서 해 줘.

> 진행 중인 **웹툰** 작업을 확인해 줘. 완성된 그림과 남은 단계를 보여 주고 같은 작업에서 이어서 해 줘.

AI가 알려 주는 상태에 따라 할 일이 다릅니다.

| 상태 | 뜻 | 할 일 |
|---|---|---|
| 모델 응답 대기 (`needs_model`) | AI가 계획·집필·검토를 처리할 차례 | “이어서 해 줘” |
| 인터뷰·승인 대기 | 내 결정이 필요함 | 질문에 답하거나 결과를 보고 승인·수정 |
| 이미지 실행 대기 | 이미지 모델·키·권한 확인이 필요함 | 쓸 모델과 비용을 확인하고 선택 |
| 검토 실패 | 검토가 끝나지 않았거나 문제가 발견됨 | “실패 이유와 남은 결과를 보여 줘” |
| 글자 배치 실패 (`layout_blocked`) | 말풍선이 얼굴을 가리거나 순서가 꼬임 | 문제 부분만 다시 배치해 달라고 요청 |
| 다른 작업이 사용 중 (`PROJECT_BUSY`, `WEBTOON_BUSY`) | 같은 작품을 다른 실행이 고치는 중 | 그 실행이 끝난 뒤 이어가기. 잠금 파일은 지우지 않기 |

AI 도구를 닫으면 작업도 멈춥니다. 배경에서 몰래 계속되지 않습니다.

이미지를 다시 요청하기 전에 이미 만들어진 파일이 있는지 확인하세요. 이미지 서비스는 그림을
다 그렸는데 파일을 가져오기 전에 멈췄을 수 있습니다. 확인하지 않으면 같은 그림 값을 두 번 냅니다.

## 검사는 통과했는데 내용이나 그림이 어색해요

검사 통과는 “문제없음”이 아닙니다. 어디가 어색하고 원래 어떻게 되길 바랐는지 함께 말하면
고칠 범위를 좁힐 수 있습니다.

> 이 대사는 앞 질문에 대한 답이 아니야. 원작의 앞뒤 문맥을 확인하고 이 대화만 고쳐 줘.

> 전투 중에 적이 갑자기 반대편으로 옮겨 갔어. 이어지는 컷의 동선을 확인하고, 다시 그릴 범위부터 알려 줘.

웹툰은 대본·구도·그림·글자 배치를 따로 고칩니다. 말풍선 위치만 문제라면 그림을 다시 그릴
필요가 없습니다. [웹툰 고치기](WEBTOON.md#고치거나-이어서-만들기)를 보세요.

## 원고나 설정 파일을 직접 고쳤어요

> 원고와 설정을 직접 고쳤어. 바뀐 내용을 먼저 확인하고, 필요한 검사와 반영 절차를 알려 줘. 다음 화는 아직 쓰지 마.

어디를 고쳤느냐에 따라 할 일이 다릅니다.

- **마지막 화:** 검사 후 승인하면 바로 반영됩니다.
- **앞 화:** 그 뒤 화들의 상태를 다시 계산해야 할 수 있습니다. 뒤 화 원고를 자동으로 다시 쓰지는 않습니다.
- **세계·인물 설정:** 앞으로의 계획에 미치는 영향을 검토합니다.

웹툰 제작 중에 원작을 고쳐도 진행 중인 웹툰에는 자동으로 반영되지 않습니다. 웹툰 대본을
직접 고쳤다면 무엇을 바꿨는지 알리고 다시 검토해 달라고 하세요. `.vibelore/` 폴더는
직접 고치지 않습니다.

## 소설을 이전 화로 되돌리고 싶어요

> 소설을 5화 시점으로 되돌릴 수 있는지 확인해 줘. 보관될 현재 파일과 되돌린 뒤 달라지는 범위를 먼저 보여 줘.

되돌릴 수 있는 시점과 영향을 확인한 뒤 진행합니다. 현재 파일은 보관 폴더로 옮겨지지만,
이 기능을 백업 대신 쓰지는 마세요. 소설을 되돌려도 웹툰은 그대로 남습니다.

## 무엇을 백업해야 하나요?

AI 도구를 멈춘 뒤 **작품 폴더 전체를 숨김 폴더까지 포함해** 다른 곳에 복사하세요.

| 폴더 | 들어 있는 것 |
|---|---|
| `world/`, `characters/`, `chapters/`, `summaries/` | 설정과 원고 |
| `webtoon/` | 승인한 웹툰 대본·기준 그림·완성본 |
| `.vibelore/` | 진행 중인 후보, 검토·승인 기록, 되돌리기 기록 |

원고만 복사하면 진행 중인 작업과 검토 기록은 되살릴 수 없습니다. Git으로 백업한다면 숨김
폴더와 이미지가 빠지지 않았는지 확인하세요. API 키는 공개 저장소에 넣지 마세요.

상태 코드나 수동 복구가 필요하면 [운영·복구 상세 절차](OPERATIONS.md)를 보세요.
